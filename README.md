# Insight Wave - AI-Powered Migration Planning

Insight Wave is an advanced, multi-agent framework designed to automate and streamline the process of planning cloud migrations. It leverages the power of Generative AI to analyze raw server discovery data, normalize it, generate strategic migration blueprints, assign servers to logical waves, and validate the entire plan for quality and integrity.

The framework is built using the Google Agent Development Kit (ADK) and features a user-friendly web interface for seamless interaction.

## Key Features

- **Automated Data Ingestion**: Ingests server discovery data directly from Google Cloud Storage (GCS).
- **Intelligent Data Normalization**: Consolidates multiple, disparate CSV data sources into a single, clean "Golden Record".
- **Strategic Blueprint Generation**: AI-driven analysis to create a `Migration Blueprint` that defines data-driven rules for grouping servers into waves.
- **Logical Wave Assignment**: Automatically assigns every server to a migration wave based on the approved blueprint.
- **Wave Quality Scoring (WQS)**: Validates the final plan for data integrity and calculates a quality score for each wave based on cohesion, risk, and simplicity.
- **Interactive UI**: A modern chat-based web interface for interacting with the agents, providing feedback, and viewing results.
- **Documentation Generation**: Creates migration pattern documents and runbook templates for various source-to-target scenarios.

## Architecture

Insight Wave uses a modular, agent-based architecture. A master `root_agent` delegates tasks to specialized sub-agents, each responsible for a specific part of the workflow.

### Frontend

- **Framework**: Angular with Angular Material components.
- **Interface**: A chat-based UI (`chat.component.ts`) that allows users to interact with the backend agents in a conversational manner.
- **Functionality**: Supports starting new sessions, viewing chat history, and rendering complex outputs like markdown tables and links generated by the agents.

### Backend Agents

The core logic resides in a series of Python agents built with the Google ADK.

- **`root_agent`**: The master router. It analyzes the user's initial prompt and delegates the task to either the `migration_agent` (for data processing) or the `pattern_doc_agent` (for documentation).

- **`migration_agent` (SequentialAgent)**: Orchestrates the main data-driven wave planning workflow. It calls the following agents in sequence:
  1.  **`ingestion_agent`**: Fetches data from a GCS path provided by the user.
  2.  **`config_normalizer_agent`**: Inspects the data schemas, proposes a data consolidation configuration, and generates a unified "Golden Record" CSV.
  3.  **`blueprint_generator_agent`**: Analyzes the Golden Record to create a strategic `Migration Blueprint` JSON, which contains the rules for wave creation.
  4.  **`grouping_and_validation_agent` (SequentialAgent)**: A sub-orchestrator that performs the final steps:
      - **`group_assignment_agent`**: Assigns servers to waves using the blueprint and refines wave sizes.
      - **`validation_agent`**: Performs data integrity checks and calculates the Wave Quality Score (WQS).
      - **`report_export_agent`**: Generates and provides links to the final reports.

- **`pattern_doc_agent`**: A conversational agent that helps users generate migration documentation (runbooks, planning docs) by asking for the source and target environments.

## Prerequisites

- Python 3.11+
- Node.js v18+ and npm
- Google Cloud SDK (`gcloud`) installed and authenticated.
- Google Agent Development Kit (ADK) CLI.

```bash
pip install google-adk
```

## Setup Instructions

Follow these steps to set up both the backend and frontend for local development.

### 1. Backend (Python Agents)

From the root directory of the project:

```bash
# 1. Create and activate a Python virtual environment
python -m venv venv
source venv/bin/activate

# 2. Install the required Python packages
pip install -r requirements.txt

# 3. Authenticate with Google Cloud
gcloud auth application-default login
```

### 2. Frontend (Angular UI)

Navigate to the `frontend` directory to install dependencies:

```bash
# 1. Change into the frontend directory
cd frontend

# 2. Install npm packages
npm install

# 3. Return to the root directory
cd ..
```

## How to Launch

The `adk web` command starts a local web server that serves both the agent backend and the Angular frontend.

**Run this command from the root directory of the project:**

```bash
adk web
```

This will:
1.  Discover the agents defined in the `insightwave` package.
2.  Start a backend server to handle API requests to the agents.
3.  Build and serve the Angular frontend application.
4.  Provide you with a URL (usually `http://127.0.0.1:8000`) to access the Insight Wave UI in your browser.

## Example Usage

Once the application is running, you can interact with the `root_agent` via the chat interface.

### Data-Driven Wave Planning

To start the main wave planning workflow, provide a prompt with a path to your discovery data in a GCS bucket.

> **User Prompt:** `Analyze the server data located at GCS Bucket gs://my-discovery-data-bucket/ and generate a migration wave plan.`

The `migration_agent` will then execute its sequence of sub-agents, presenting the configuration and blueprint for your approval at each major step.

### Generating Documentation

If you need a generic migration document, you can ask for it directly.

> **User Prompt:** `I need a migration runbook.`

The `pattern_doc_agent` will then ask you clarifying questions (like the target environment) before providing a link to the correct template.
